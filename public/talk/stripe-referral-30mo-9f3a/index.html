先说清楚：数据是什么、不是什么

是

SimilarWeb 估算的 web referral

seo.box 每月发布跳转到 checkout.stripe.com 的 Top 100 引流域名 —— 谁的网站把用户送到了 Stripe 托管收银台。可视为「谁在真收到钱」的代理指标。

不是

Stripe 全量交易数据

Top 100 仅覆盖总引流的 55–68%；不含嵌入式结账、App 内支付、自定义域名收银台。掉出榜单 ≠ 不再赚钱。

假说 A

自定义域名收银台

大客户启用 checkout.自家域名，referral 不再指向 checkout.stripe.com。最能解释「同月集体消失」。

假说 B

嵌入式结账迁移

迁到 Embedded Checkout / 自建支付页，页面不再跳转。

假说 C

SimilarWeb 口径调整

面板样本或抓取方式变更，同时解释总量跳涨与个体消失。

结论：2026.04 前后不可直接同比06 / 10
