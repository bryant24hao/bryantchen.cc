●  01  ·  about

关于我 who's behind this

前大厂产品经理，现独立开发者。前 3 个月做了很多没有用的小玩具，最近在「无用」和「商业」之间探索平衡。

●  02  ·  demoshow

用颜色看世界

从你的照片中提取颜色，作为相框背景，生成一张 ColorWalk 照片。

A photo, a color, a day.

●  02  ·  differentiation

差异化功能

  • 自动加标注 — Location · Emoji · Time
  • 文学时间模式
    • 照片的时刻，自动匹配一句文学中的句子
  • 相框 — 多种排版与画幅

●  03  ·  the idea

为什么想做这款应用？

  • 流行趋势 — 去年起 ColorWalk 这个词开始流行，今年春天小红书也在推这个话题；当时预测会有不错的流量。
    • 很早就把它放进了 100 bad ideas
  • 用 HEX 色值去认知世界和时间，是一件很酷的事情
    • 之前先做了一个文学时钟插件
  • 把这两个主题结合在一起，做成 iOS App 会怎么样？
●  04  ·  prototype

原型设计 from voice to demo

  • Claude Design — 通过语音输入沟通完整的需求，出一版核心页面设计
    • ▸ 打开 Claude Design 预览（10 layouts canvas）
  • Claude Code — 半天时间完成第一版 Demo 的开发
●  05  ·  the gap from 50 to 80

想清楚自己想做的到底是几十分的产品，很重要。

●  05  ·  craft & differentiation

细节与差异化打磨

  • 结对 Debug
    • 就像坐在 Agent 的身边，对着电脑指指点点
    • （和当年 PM/设计师站在工程师背后没区别）
  • 异步开发
    • GitHub 管理 issue 和 Milestone
    • 你不在场时，Agent 也可以放心干活
●  06  ·  ship it

上架 submitting to the App Store

  • 提前准备账号和材料 — 开发者账号、隐私政策、截图、关键词…
  • 第一版 ready 就可以提审了
    • 付费版本的提审，提前要准备的材料更多（IAP、订阅、Privacy Manifest…）
●  07  ·  lessons

踩过的坑 things I'd do differently

  • 有好的想法早点开始
    • 热点来的时候「在场」很重要
    • 小红书 ColorWalk 数据已经爆了 + 五一出行是绝佳产品窗口期
  • 早点跑通第一个完整产品闭环
    • idea → 原型 → demo → 打磨 → 上架，每一节都积累经验
