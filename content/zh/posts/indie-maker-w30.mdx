## 关于「审美疲劳」的讨论

> 这周刚好刷到一条这样的帖子「我现在已经对黑白灰 + 波点 + 粉色蝴蝶结 + 音符 + 天使翅膀、再加细体英文和韩文字符等的东西审美疲劳了，已经铺满下沉平台。原来觉得酷的东西，突然变成被硬塞进嘴里的炒饭乌冬」。
>
> 很有启发的一个观察。

这两年，当 AI 把各种内容的生产门槛降低之后，大家总是不自觉地提到「审美或是品味」。结合上条帖子，我和 AI 开始聊：

1、为什么原来觉得好看的东西，现在不喜欢了？

审美不太能当成「好不好看」来理解。更像是：一群人在一段时间里共用一套符号，用着用着这套符号从「有品味」变成「一眼能点名」。一旦能点名，美就退成库存。

一言以蔽之，审美在于稀缺性。

2、盲目跟风会让原本好看的东西因为泛滥而失去美吗？

会因为泛滥而失去美，但不是东西变丑了。蝴蝶结还是那个蝴蝶结。变的是它不再能说明什么：原来它说「我看见了、我选了」，跟风之后它只说「我和信息流里的人用同一套」。美还在物上，失效的是区分。所以不是「用多了就丑」，是「同时、同款、无约束地铺开」把信号用尽了。

以上，Think different 和 Make something different 的重要性在这里体现了出来。Think different 是看见那套符号已经能被点名了，就不要再往里加。Make something different 才是真的：做出还不能被一眼点名的东西。只把 Think different 当口号，很快本身也变成库存。

## 学会偷懒

周五晚上，重新整理运营和经营数据看板。之前统计 ASC（App Store Connect，苹果开发者看数据的平台）数据还是自己在导出，一个是没办法做到天天更新，另一个是麻烦。

于是问了下 AI，能不能自动获取，果然有 API。所以这类工作还是不要太勤劳，要懂得偷懒和借助 AI 的能力。

好了，这下经营数据看板正式升级了。

之后有机会写篇文章讲讲我是怎么利用 AI 自动化获取和做业务诊断、跟踪的。不知道会不会有人对我这套经营、运营看板感兴趣？

## Token 盈余

记得很多年前我读过一本书叫《认知盈余》，书里面的内容已经记不清了，但这个词语我很喜欢，那么在 AI 时代，我觉得「Token 盈余 = 认知盈余」。为什么会这么说呢？

最近有这个感受的瞬间是：

刚买了 Grok 的 300 刀套餐（后面会细说），用量其实还是比较盈余的，所以这周一边开发 ColorWander、一边开始完整地整理了一下 Obsidian，算是做了一次知识库的家务。

整理完知识库之后，整个关于我自己的 context 都得到了很好的沉淀。在整理过程当中做了几件事情，一件事情是把个人网站、各个常用的社交媒体上之前发的所有帖子和内容都完整地整理出来了。后面和 AI 聊，或者做一些自我剖析和自我拆解，其实也会更加容易。

用这个例子想说的是，因为 Token 多，所以会想着有没有之前没时间、没资源做的需求，顺便用盈余的 Token 来搞一下。类似的观察还有 —— 每次 Codex 发重置卡，自己或者身边的朋友总会做出一些新东西来。

综上，AI 时代，Token 再多也不算多，保持 Token 盈余（可以用不完，但是一定要有）。

## 这周让我觉得惊喜的产品：Grok Build 和 Grok Bot

接着上一条「Token 盈余」说，上周日凌晨刷到 Grok 的打折活动，看了下实在太划算了，本着抢到就是赚到的原则，果断下手了！

下手之后，这周开始在部分非核心工作场景用 Grok 的 CLI Agent（后简称 Grok Build，对标 Claude Code / Codex）。

Grok 的 TUI（Terminal UI，命令行界面）设计水平、好看程度、中间过程的透明度和友好程度，说吊打 Claude Code 毫不夸张。

![Grok Build 的 TUI 启动界面](/images/posts/indie-maker-w30-grok-build-tui.png)

在闲聊场景用 Grok Bot，该怎么形容呢，我觉得 Grok Bot 就像是工作中遇到的一类人：不是最聪明、业务能力最强的，但是 ta 干得真的很快，能快速交付一个 70 分的东西，如果对于结果要求没那么高，还是觉得很惊喜的。

另外 Grok Bot 把年初 OpenClaw 火的一些概念（心跳机制、插件生态的连接、Agent 群聊）都融进来了，鉴于此前 Grok 的拉垮程度，这次他们交出的完成度还算凑合（有传言说是 Cursor 团队搞的）。我这周的周报和日记，都是散步时或者在车上、地铁上，边和 Grok Bot 聊边直接整理到 Notion 上的。

不过，Grok 现阶段的智力水平肯定还是没办法和 SOTA 模型（Fable5、GPT5.6 Sol）相比，所以我无法做到把最核心的工作交给 ta。
