I've been setting up a separate official Instagram account for ColorWander, so I can keep overseas content and user feedback in one place instead of having everything live under my personal account.

I hit a snag during signup. Worth writing down.

At first, I tried registering directly with a phone number, selecting +1 for a US number. But the verification code just wouldn't send. It kept saying it would send the code to a number starting with +86, with the rest of the digits wrong too. After several rounds of trying, I finally worked out what was happening: Instagram identifies your location from the network you're on. As long as you're using a network in China, whatever country code you choose on the signup page gets corrected to +86 based on your IP location. Naturally, the verification code couldn't get through.

Then I changed the order: I registered the account with an email address first, went into settings after signup, and linked the phone number separately. It worked on the first try.

If you're also signing up for an overseas platform from a network in China and get stuck on phone verification, don't keep fighting that step. Create the account with an email address first, then add the phone number once the account exists. It can save a lot of back-and-forth.
